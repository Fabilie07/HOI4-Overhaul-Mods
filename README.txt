Here's how to add the Development Build:

1. Clone this Repository to a directory of your choosing, either by using the GitHub Desktop App or downloading its contents as a .zip file

2. Copy the template_descriptor.mod file to "Documents/Paradox Interactive/Hearts of Iron IV/mod"
3. Rename it accordingly (e.g. "aircraft overhaul.mod")
4. Replace <Mod-Path> with your Repository Directory Path (Make sure to use "/" seperators, not "\")
5. Replace "aircraft overhaul" with the repository-internal path of the mod you wish to use (steps 4 and 5 can be combined as one)
6. Repeat steps 2-5 for each mod you want to have access to

7. If the mods don't show up in your Launcher when restarting the game, delete "Documents/Paradox Interactive/Hearts of Iron IV/launcher-v2.sqlite" !!This will remove all of your Playsets, so make sure to create Backups before!!
