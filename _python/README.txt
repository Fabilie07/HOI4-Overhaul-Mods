To convert Saved Designs into usable Code, copy "reformat_to_create_equipment.py" into "Documents/Paradox Interactive/Hearts of Iron IV/session_persistence/equipment_designs/"
You need to have Python installed in order to execute the file.

Simply execute "reformat_to_create_equipment.py" and it will create a new file called "equipment_designs_reformatted.txt", containing the converted Equipment Designs.
You can copy them from there into any ai_equipment file or create_equipment_variant Effect with minimal changes.
